# Fun-Mod 2.0

Minecraft Java Edition 1.21.11 · Fabric

Fun-Mod 2.0 is being rebuilt on the separate branch fun-mod-2.0-1.21.11. The original 26.2 branch is untouched.

## Included in this prototype
- Fun-Mod 2.0 creative tab
- Custom Lucky Block outcomes and Rainbow Block
- Gold bracelet, necklace, four effect earrings, dollar and euro items
- Jewelry display-case block and a mannequin item that places an armor stand
- Quick-summon items for a named golem, Warden boss and wandering trader
- Crafting recipes, loot tables, Turkish and English translations, pixel-art textures

Some features remain prototypes: summoned creatures currently use vanilla models; dedicated Netherstorm and Luck dimensions, custom structures and AI, customer purchases and cash-register logic, and a fully interactive display case are not implemented yet.

## Obtain the built JAR
GitHub Actions automatically builds this branch. Open the repository's Actions tab, select the latest build-fun-mod run, and download the artifact named Fun-Mod-2.0-Minecraft-1.21.11. The downloaded ZIP contains the JAR. Put the JAR into the Minecraft mods folder with Fabric API installed.
